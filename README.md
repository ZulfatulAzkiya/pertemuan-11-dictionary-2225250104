## Deskripsi
Program ini mempelajari dictionary dalam Python,
mulai dari membuat dictionary, mengakses data,
menambah dan mengubah data, menghapus data,
melakukan iterasi, hingga menggunakan dictionary bersarang.

## Daftar Latihan
1. Dasar dictionary
2. Mengakses data menggunakan get()
3. Menambah, mengubah, dan menghapus data
4. Iterasi dictionary
5. Dictionary bersarang
6. Fungsi pencarian data mahasiswa
7. Praktik sistem data mahasiswa

## Cara Menjalankan
1. Buka folder proyek di VS Code.
2. Pilih Terminal > New Terminal.
3. Jalankan file yang ingin dicoba.

Contoh:
python latihan/01_dasar_dictionary.py

Untuk praktik:
python praktik/data_mahasiswa.py

## Konsep yang Dipelajari
- Key dan value
- get()
- in
- keys(), values(), dan items()
- update() dan pop()
- Dictionary bersarang
- Fungsi dan pencarian data
